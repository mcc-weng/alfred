# 蔥油白切雞 + 燙青菜

fast · ~30 min · 2人份 — 排入 2026-06-09 · 技巧:浸水白切法 + 滾油逼香

**🔪 備料(開火前全部完成 — mise en place)**

蛋白質:
- 雞胸肉 2塊(共約400g)→ 提前30分鐘從冰箱取出回溫;用廚房紙拍乾表面

蔬菜:
- 青江菜或小白菜 300g → 洗淨,大株對半縱切
- 青蔥 5–6根 → **白段**切5cm段(用於浸水)·**綠段**切細花分2堆:
  一堆用於蔥油澆淋(1大把),一堆盛盤裝飾(少許)
- 薑 5片 → 1片薑切細絲(搭配蔥油)

醬汁:
- 醬油 2大匙
- 蠔油 1大匙
- 芝麻油 1茶匙
- 雞湯(浸雞的水) 2大匙 → 煮好後取

蔥油:
- 中性油 3大匙(葵花油或菜籽油;不要橄欖油,香氣會搶味)

⏱ 提前準備:雞胸回溫30分鐘,未回溫的雞胸浸水容易外熟內生。

**👨‍🍳 步驟**

1. 準備浸雞的水:鍋中加足量清水(能蓋過雞胸),放入蔥白段 + 薑片3–4片 + 鹽1茶匙。
   大火煮滾。約5–7分鐘。

2. 水滾後放入雞胸,**立刻轉最小火** — 水面保持幾個小泡、偶爾輕微翻動的狀態
   (「barely simmering」)。**絕對不能大滾** — 大火浸水 = 雞胸又乾又柴的最大原因。
   蓋鍋浸煮13–15分鐘(視厚度)。約15分鐘。
   *感官判斷線索:用竹籤或細筷戳最厚的地方,滲出汁液清澈(不帶粉紅)= 熟透。*

3. 雞胸撈起,馬上放入裝有冰塊+冷水的大碗中(沒有冰塊就用冷水)。
   靜置5分鐘 → 讓肉質收緊更Q彈、表皮更光滑好切。約5分鐘。
   *同時保留浸雞的高湯備用。*

4. 同一鍋高湯加鹽(嚐一下鹹度),大火滾起,汆燙青菜1–1.5分鐘 —
   顏色轉鮮亮深綠、莖部稍軟仍脆(用筷子夾有輕微阻力)= 剛好斷生。撈起瀝乾擺盤。

5. 調醬:醬油2大匙 + 蠔油1大匙 + 芝麻油1茶匙 + 雞湯2大匙混合均勻。

6. 雞胸撈出,用鋒利的刀斜切薄片(約5mm),切逆紋方向(刀與肌肉紋路垂直)。
   鋪在青菜上,淋醬汁。把蔥花 + 薑絲整齊擺在雞肉最上方。

7. **蔥油重頭戲**:小鍋倒中性油3大匙,**中大火加熱1–1.5分鐘**,油面開始出現細小波紋、
   邊緣第一縷輕煙飄起 = 約160–180°C。**馬上澆到蔥花薑絲上!**
   你會聽到猛烈的「滋———」聲,蔥花瞬間轉熟,香氣四散。立即上桌。

**⚠️ 新手最容易翻車的地方**
- **大火滾水浸雞 = 柴雞保證**:轉小火是唯一真理。浸水過程鍋蓋蓋上保溫,
  偶爾掀開確認水面狀態。若水全停了就開最小火。
- **油不夠熱 = 蔥香不出來**:油要到「微微冒煙」才澆,太涼只是泡軟蔥花,無香氣衝擊。

**🔥 主廚秘訣**
- **切逆紋很重要**:雞胸肌肉纖維長,順紋切 = 嚼不斷;逆紋切(刀與纖維垂直)= 嫩。
- **浸雞水就是高湯**:加了薑蔥鹽煮出來的水本身就是雞湯,做醬汁或隔天煮湯麵。
- **冰浴讓皮Q彈**:這個步驟不偷懶的話,口感差距很明顯。雞皮本身沒有味道,但那個彈感是享受。

**✅ 怎麼知道完成了**
- 雞肉切面全白無粉紅、汁液清澈
- 澆油那一刻有響亮的「滋」聲
- 蔥花呈半熟狀態,有焦香但不焦黑
— 小當家 🔥
