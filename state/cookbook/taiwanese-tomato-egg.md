# 台式番茄炒蛋 + 白飯

fast · ~20 min · 2人份 — 排入 2026-06-09 · 技巧:先炒蛋後炒番茄(「先蛋後茄法」)

**🔪 備料(開火前全部完成 — mise en place)**

蛋類:
- 蛋 4顆 → 打散,加鹽 1/4 茶匙 + 白胡椒少許;用筷子繞圈打30下讓蛋白蛋黃完全均勻(不起泡)

蔬菜:
- 番茄 3顆中型(約400g)→ 切角,每顆8份;切面朝上靜置讓汁液稍微滲出
- 大蒜 2瓣 → 拍碎切末
- 蔥花 2根 → 切花(裝飾用,最後才下,生蔥香氣最強)

醬料:
- 番茄醬 1大匙(增甜鮮,可略但建議加)
- 糖 1茶匙(圓潤酸甜的靈魂)
- 鹽適量

⏱ 提前準備:白飯提前20分鐘下鍋或加熱 — 這道菜10分鐘就炒完,飯要先就位。

**👨‍🍳 步驟**

1. 確認白飯已在煮或已熱好。計時10分鐘。

2. 熱鍋中大火 — 手放鍋面10cm感到灼熱,鍋面開始微微冒煙。倒油1.5大匙,
   油紋晃動出現波紋時下蛋液。約30秒熱鍋。
   **關鍵:下蛋後不要立刻攪!** 等邊緣約1–2cm凝固成白色(約10–15秒),
   再用鍋鏟從邊緣往中心大片推折 — 蛋會形成漂亮的大塊波浪狀。
   蛋表面還有光澤、中心略濕時馬上盛起!約1.5分鐘。
   *為什麼:8成熟起鍋 — 之後回鍋還會受熱,現在超過就變橡皮。*

3. 同鍋補油1茶匙,中大火,下蒜末炒香30秒(聞到蒜香、微微黃色)。
   下番茄翻炒 — 要聽到接觸鍋底的「滋滋」聲;沒聲音代表鍋溫不夠,立刻加火。
   約3分鐘,番茄顏色從亮紅轉深紅、開始出湯汁、切面軟化。

4. 番茄出汁後加糖1茶匙 + 番茄醬1大匙 + 鹽少許拌勻。
   轉大火,讓湯汁稍微濃縮收一下,約30秒。

5. 下剛才的炒蛋,快速翻拌8–10下讓蛋裹上番茄汁。試味,不夠鹹加鹽,不夠甜加一點糖。
   撒蔥花,即刻起鍋盛飯。約1分鐘。

**⚠️ 新手最容易翻車的地方**
- **蛋炒太老變橡皮**:蛋8成熟就要起鍋;看到蛋失去「濕潤光澤」代表已過頭了。
  過熟的蛋加再多番茄汁都救不回。寧可嫩一點。
- **番茄沒出汁、整鍋乾乾的**:鍋溫不夠。番茄下鍋要聽到「滋滋」聲,
  無聲 = 加火。番茄出汁後湯會很多,這是正確的。

**🔥 主廚秘訣**
- **糖是這道菜的靈魂**:不是要讓它變甜,是讓酸味「圓潤」。沒有糖,番茄炒蛋就缺少那個餘韻。
- **大塊炒蛋才好看**:別把蛋炒碎。大片推折 = 豐盛感;碎屑 = 家常隨便感。
- **番茄醬是作弊器**:稍微增加層次,餐廳的秘密。用不超過1大匙,多了會假。

**✅ 怎麼知道完成了**
- 番茄保有形狀(不是糊爛),醬汁有適量光澤感
- 蛋塊鬆軟金黃,彈性好,不是橡皮感
- 嚐起來酸甜平衡,有番茄的自然鮮甜
