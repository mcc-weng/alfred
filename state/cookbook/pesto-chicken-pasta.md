🍳 **週五 — 青醬雞腿義大利麵 + 凱薩沙拉**  (fast · 約30分 · 2人份)

**🔪 備料(開火前全部完成)**
- 去骨雞腿肉 約300g,廚房紙巾壓乾,兩面撒鹽+黑胡椒
- 義大利麵 200g(櫥櫃)· 青醬 3–4大匙(**待購 — 見缺貨清單**)
- 小番茄如有就對切一把 · 帕瑪森起司
- 凱薩沙拉包 1包(醬和起司都在裡面 — 上桌前才拌!)
- 大鍋鹽水燒著(水要夠鹹 — 像海水,這是麵條唯一吸鹽的機會)

**👨‍🍳 步驟**
1. 平底鍋中火,少油,雞腿**皮朝下**下鍋 — 然後不要動它,8–10分。(皮的脂肪要時間慢慢逼出來才會金黃酥脆;一直翻=軟皮)前4分可以拿鍋鏟輕壓,讓皮全面貼鍋。
2. 等皮煎的同時:義大利麵下滾水,照包裝時間**減1分**。瀝水前**舀起一馬克杯麵水**(乳化醬汁的關鍵,別倒掉!)。
3. 雞腿翻面再煎3–4分至熟(最厚處切開不見粉紅)。起鍋靜置3分,切條。
4. **關鍵步驟 — 關火**:麵瀝水倒回鍋裡(離火!),下青醬+2–3大匙麵水,快速拌勻到醬亮亮地裹住每根麵。(**青醬絕對不能開火煮 — 羅勒受熱會發黑轉苦**,這是青醬麵最大的秘密)
5. 太稠加麵水、太稀再拌一下。拌入小番茄,擺上雞腿條,刨帕瑪森。
6. 沙拉包上桌前才拌醬(早拌會軟爛出水)。

**⚠️ 新手最容易翻車的地方**
- 青醬下鍋加熱 → 顏色發黑、味道發苦。永遠離火拌。
- 麵水倒光了 → 醬乾巴巴掛不上麵。先舀再瀝,養成習慣。

**🔥 主廚秘訣**
- 「乳化」就是:澱粉麵水+油脂醬料快速攪拌=絲滑亮澤的醬感 — 餐廳麵和家常麵的差距就在這杯水。
- 雞皮要更脆:下鍋前壓得越乾越好,鹽提早10分鐘撒幫助逼水。

**✅ 怎麼知道完成了**
- 雞皮金黃酥脆有聲、麵條每根裹著亮綠色醬、青醬還是鮮綠不是墨綠。
