# 韓式嫩豆腐鍋 (순두부찌개) + 白飯

batch · ~35 min · 2人份 + 隔天午飯份 — 排入 2026-06-09 · 技巧:辣椒粉炒香底油、嫩豆腐手工豁入

**🔪 備料(開火前全部完成 — mise en place)**

豆腐/蛋:
- 嫩豆腐(silken tofu / 순두부) 400g · 1盒 → 不切,待會直接用湯匙豁入
- 蛋 2顆 → 分別打入小碗備用(每碗一顆,最後各人一顆下鍋半熟)

蔬菜/菌類:
- 大蒜 3瓣 → 切末
- 青蔥 2根 → 白段切小圈(炒底);綠段切花(最後撒)

辣底醬:
- Gochugaru(韓式辣椒粉) 1.5大匙(怕辣就1匙,喜辣加到2匙)
- Gochujang(韓式辣醬) 1大匙(增深度;若沒有,多加0.5匙gochugaru)
- 醬油 1大匙
- 芝麻油 1茶匙(最後添香用)

湯底:
- 雞高湯 600ml(2.5杯;用高湯塊+水即可)
- 清水 100ml

⏱ 提前準備:高湯可以提前用熱水溶好備用;嫩豆腐從冰箱取出退涼。

**👨‍🍳 步驟**

1. 開中火,鍋中加油1大匙,下蔥白圈 + 蒜末,炒至透明出香(約1.5分鐘,聞到蒜香)。

2. **辣椒粉炒香是關鍵**:下gochugaru 1.5大匙 + gochujang 1大匙,轉中小火慢炒1–2分鐘。
   *感官線索:辣椒粉開始變深紅、油變成橘紅色、聞到濃郁辣香(不是嗆辣,是香)= 正確。
   火太大會焦苦,要小心。*
   *為什麼:乾辣椒粉需要油+熱才能釋放出顏色和香氣,直接加水不會有這個層次。*

3. 加入高湯600ml + 清水100ml + 醬油1大匙,大火煮滾。約5分鐘。
   滾起後試一下鹹度;不夠鹹加醬油或鹽。

4. **豁入嫩豆腐**:用大湯匙,從盒中舀出大塊豆腐,輕輕放入湯中(不要攪碎)。
   嫩豆腐像果凍一樣嬌嫩,越少攪拌越好。中火煮3分鐘讓豆腐入味。

5. **[Batch步驟]**:此時先舀出一半的鍋(約400–500ml湯+豆腐)裝入容器,
   放涼後冰箱保存 — 這是隔天的午飯。不要加蛋進去(明天再加)。

6. 剩下那半鍋轉中大火,把事先打好的蛋分別輕輕滑入湯中(不要攪散)。
   關火,用餘熱把蛋燜30秒 — 蛋白凝固、蛋黃仍流動 = 完美。
   *喜歡全熟蛋:讓它在火上再1分鐘。*

7. 淋幾滴芝麻油,撒蔥花,連鍋上桌配白飯。

**⚠️ 新手最容易翻車的地方**
- **辣椒粉炒焦 = 整鍋苦**:炒辣椒粉的火一定要小,油一直是澄清狀態就代表溫度對;
  油開始冒煙就太熱了。
- **嫩豆腐全碎掉**:舀進去以後就不要再攪鍋。可以晃一下鍋,但別用鍋鏟翻攪。

**🔥 主廚秘訣**
- **一人一顆蛋**:韓式嫩豆腐鍋最後那顆半熟蛋是靈魂,蛋黃流出來跟湯拌著吃,不要省。
- **隔夜更好吃**:批次做好的那份隔天入味後更深沉,煮滾後再加個新鮮蛋就是完整的一餐。
- **辣度控制**:Gochugaru只辣不苦;gochujang有鹹有甜有深度。兩者比例決定整鍋個性。

**✅ 怎麼知道完成了**
- 湯色橘紅、有光澤、香氣撲鼻但不嗆
- 豆腐保持大塊,輕輕晃動鍋子才碎
- 蛋白全白凝固、蛋黃中心稍微流動
