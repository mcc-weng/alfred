# 台式茶碗蒸 + 炒青菜 + 白飯

fast · ~30 min · 2人份 — 排入 2026-06-09 · 技巧:蛋液過篩 + 中火蒸(「蛋奶布丁法」)

**🔪 備料(開火前全部完成 — mise en place)**

茶碗蒸:
- 蛋 3顆 → 輕輕打散(不要打出泡沫,慢慢攪就好)
- 雞高湯 375ml(常溫或微溫;用高湯塊溶好)— **蛋:高湯=1:2.5(體積比)**是絕對比例
- 醬油 1茶匙(淡口味)
- 鹽 1/4茶匙
- 細網篩 × 1(沒有就用濾茶器;這個步驟不可省)
- 深碗或茶碗 × 2(能放進鍋子蒸的容器)

選配(可加可不加,增加層次):
- 蝦仁 2顆/碗(提前汆燙)或
- 鴻禧菇少許(提前燙軟放碗底)
- 蔥花少許(最後撒)
- 芝麻油幾滴(完成後)

青菜:
- 青江菜或小白菜 250g → 洗淨切段
- 蒜末 2瓣
- 鹽、油適量

⏱ 提前準備:高湯提前降溫至常溫(不能是燙的,熱高湯倒進蛋液會讓蛋開始熟)。
白飯同步煮。

**👨‍🍳 步驟**

**茶碗蒸:**

1. 打蛋:3顆蛋輕輕打散,不打發,不起泡 — 泡沫蒸出來後是表面小洞。
   加醬油1茶匙 + 鹽1/4茶匙攪勻。

2. **加高湯**:常溫高湯慢慢倒入蛋液中,邊倒邊輕輕攪拌均勻。
   蛋:高湯的體積比是 **1:2.5** — 比例越高湯越嫩;低於1:2會硬。
   *計算方式:3顆蛋打散後約150ml,乘以2.5 = 375ml高湯。*

3. **過篩是決定口感的步驟**:把蛋液倒過細篩,去掉蛋白膜(chalazae)和氣泡。
   篩後的液體應該非常均勻、幾乎沒有泡沫。若表面還有泡,用廚房紙輕輕點掉。

4. 把蛋液等量倒入2個深碗。表面蓋上保鮮膜(刺幾個小洞)或鋁箔紙 —
   **目的是阻止水蒸氣的水珠滴在蛋液表面**(滴水珠 = 表面凹坑)。

5. 蒸鍋水燒滾後**轉中小火**。放入碗,蓋上鍋蓋,留一條縫(約5mm)讓蒸氣散出。
   蒸13–15分鐘。
   *感官判斷:用筷子輕戳中心 — 筷子戳進去會彈回來、不會陷下去 = 熟了。輕晃碗,
   中心有輕微果凍感但不液態 = 完美。大火蒸 = 表面坑坑疤疤像月球。*

6. 完成後淋幾滴芝麻油 + 撒蔥花,趁熱上桌。

**炒青菜(與蒸蛋最後5分鐘同步進行):**

7. 大火熱鍋下油,蒜末爆香30秒,下青菜大火翻炒1.5分鐘 —
   顏色轉鮮亮深綠、莖部稍軟(「斷生」= 蔬菜轉深綠、質地微軟仍脆)= 起鍋。
   加鹽,試味。

**⚠️ 新手最容易翻車的地方**
- **大火蒸出「月球表面」**:蒸氣太強、溫度太高 = 蛋液沸騰 = 表面一堆洞。
  中小火 + 留縫。即使看起來「太慢」,堅持中小火,結果會像布丁。
- **高湯太熱倒進蛋液**:要等到高湯降至常溫(手摸碗外壁不燙)才倒入蛋液。
  太熱 = 蛋液邊緣開始熟,蒸出來一塊是熟一塊是嫩。

**🔥 主廚秘訣**
- **比例才是靈魂**:1:2.5的蛋液比例就是嫩滑如布丁的關鍵。1:2太硬,1:3太嫩會散。
  做一次就記住這個比例,一輩子受用。
- **蓋保鮮膜防水珠**:看似小細節,但水珠一滴下去表面就破了。完美的茶碗蒸表面應該如鏡。
- **台式vs日式**:日式茶碗蒸用柴魚高湯(だし)更清香;台式用雞高湯更厚實。兩種都好,
  手邊有什麼用什麼。

**✅ 怎麼知道完成了**
- 表面光滑如鏡,無氣孔,輕微金黃色
- 輕晃碗:整體輕微震動但不液態(果凍感)
- 嚐一口:滑進喉嚨不需咀嚼,帶雞湯鮮味
