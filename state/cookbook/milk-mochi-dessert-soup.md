# 鮮奶麻糬甜湯

份量：2人份
時間：約15分鐘

**Ingredients:**

甜湯（減糖版）：
- 黑糖 30g
- 水 300g
- 薑 3–4 片

麻糬（減糖版）：
- 牛奶 300g
- 地瓜粉 30g
- 糖 20g

**Steps:**

1. 將甜湯材料放入鍋中加熱至沸騰，煮至黑糖完全融化。
2. 另取一鍋，加入麻糬材料，以小火加熱並持續攪拌，煮至呈現濃稠狀即可。
