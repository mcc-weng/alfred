# 鮮奶麻糬甜湯

**食材（約2人份）**

甜湯：
- 黑糖 30g
- 水 300g
- 薑 3–4片

鮮奶麻糬：
- 牛奶 300g
- 地瓜粉 30g
- 糖 20g

---

**步驟**

1. 甜湯材料全入鍋，中火煮至沸騰，黑糖完全融化。⏱ 約5分鐘。湯汁均勻深褐、沒有黑糖顆粒就好。

2. 另起一鍋，牛奶 + 地瓜粉 + 糖先攪勻，小火邊加熱邊**不停攪拌**，煮到濃稠可以拉絲。⏱ 約6–8分鐘。
   🔥 全程小火 + 不停攪 = 不結塊不燒底的關鍵。
   ✅ 完成：湯匙舀起，麻糬糊緩慢滴落而不是水水流下去。

3. 麻糬用湯匙挖成小球放進甜湯，趁熱喝。

────────────

📌 原始食譜（來源原文，未改動 · 原份量未標示）

甜湯（減糖版）
- 黑糖 30g
- 水 300g
- 薑 3–4片

麻糬（減糖版）
- 牛奶 300g
- 地瓜粉 30g
- 糖 20g

做法
1. 將甜湯材料放入鍋中加熱至沸騰，煮至黑糖完全融化
2. 另取一鍋，加入麻糬材料，以小火加熱並持續攪拌，煮至呈現濃稠狀即可！
